# Фінальний проєкт: алгоритми та структури даних

Встановлення залежностей у віртуальне середовище:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python task01.py
```

| Файл | Завдання |
|------|----------|
| `task01.py` | Однозв'язний список: реверсування, сортування злиттям, об'єднання двох відсортованих списків |
| `task02.py` | Фрактал «дерево Піфагора» (рекурсія). Запуск: `python task02.py 8` або `python task02.py` (рівень буде запитано) |
| `task03.py` | Алгоритм Дейкстри з бінарною купою (`heapq`) |
| `task04.py` | Візуалізація бінарної купи (дерево будується з масиву купи: діти `2i+1`, `2i+2`) |
| `task05.py` | Покрокова візуалізація обходів DFS (стек) і BFS (черга), кольори від темного до світлого |
| `task06.py` | Вибір їжі: жадібний алгоритм і динамічне програмування |
| `task07.py` | Метод Монте-Карло для сум двох кубиків |

## Завдання 6: жадібний алгоритм vs динамічне програмування

| Бюджет | Жадібний (калорії) | ДП (калорії) |
|-------:|-------------------:|-------------:|
| 50  | 670  | 670  |
| 100 | 870  | **970** |
| 120 | 1120 | 1120 |

Жадібний алгоритм не завжди дає оптимальний результат: при бюджеті 100 він обирає
`cola, potato, pepsi, hot-dog` (вартість 80, 870 ккал) і 20 одиниць бюджету лишаються
невикористаними, тоді як ДП знаходить `pizza, pepsi, cola, potato` (вартість 100, 970 ккал).
